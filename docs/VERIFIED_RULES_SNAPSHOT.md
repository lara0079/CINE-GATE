# Verified rules snapshot

Checked against the official Devpost overview, IBM resource page, and official rules on 2026-08-01.

- Deadline: 2026-09-07 at 2:00 PM Pacific time.
- IBM prizes: USD 7,500, USD 4,500, and USD 3,000.
- Eligible adults may enter individually; Greece is not listed among excluded territories.
- The project must be new and created during the contest period.
- The project must be a functional web, Android, or iOS agent or multi-agent network for a media and entertainment workflow.
- Only Google Cloud AI tooling and built-in AI features of the selected partner are permitted.
- Source code must show Google Cloud runtime use through an accepted package or configuration, not merely mention it in documentation.
- IBM Bob must be used in the development process and its usage must be demonstrated.
- Confluent is optional but encouraged for the IBM track.
- A hosted project, public open-source repository, complete license, English description, and public demo video are required.
- Judging is equally weighted across technological implementation, design, potential impact, and quality of the idea.
- Stage One is a pass/fail completeness and viability check.

Re-check the live pages before final submission because terms and displayed information may change.
