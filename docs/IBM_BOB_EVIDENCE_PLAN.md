# IBM Bob development and evidence plan

## Purpose

The IBM category requires meaningful Bob use. Evidence must reflect actual work performed through the entrant's Bob account and must not be fabricated.

## Planned Bob tasks

1. Review the Milestone 5 repository and its 57 automated tests.
2. Implement the bounded review-summary navigator described in `IBM_BOB_TASK_SPEC.md`.
3. Add or improve verification for that enhancement.
4. Use Bob to diagnose and correct at least one real defect, accessibility issue, or deployment issue.
5. Review Cloud Run readiness and final repository documentation.

## Evidence to retain

- dated Bob project creation screen
- task prompts and generated change history
- before-and-after code diff
- test execution after Bob changes
- screenshot or export showing Bob participation
- concise submission note describing what Bob contributed and what was manually verified

## Integrity rule

Do not claim Bob generated or reviewed code before Bob is actually used. Do not retroactively manufacture screenshots, task history, or contribution claims.
